## HAR 接入：Interpark onestop 选座接口全量还原（v0.2 完成）

抓包 `~/Downloads/tickets.interpark.com.har`（279 请求，JX 仁川场）。完整链路已还原并落文档
`analysis/HAR-接口分析.md`。**关键事实（后续复用必读）**：

- 购票链路：world.nol.com 商品页 → `/gates/partner`（带 partner_token）→ `ent-bridge/tokenVerify`
  → `reserve-gate/goods-info` + `member-info`（**member-info 返回 signature + secureData，排队必需**）
  → `ent-waiting-api`：`secure-url`(POST signature/secureData) → `line-up`(返回 waitingId)
  → `rank?waitingId=`（轮询，放行时返回 **sessionId + oneStopUrl**）
  → `tickets.interpark.com/onestop?key=…` 进入选座。
- **鉴权不走 Cookie，走请求头 `x-onestop-session`**（= rank 返回的 sessionId）；
  另需 `x-onestop-channel: TRIPLE_KOREA`、`x-ticket-bff-language`、`x-requested-with`。
  ent-waiting-api 的 CORS 只允许 `https://tickets.interpark.com` → 只能在座位页上下文取数。
- 校时：`GET api-ticketfront.interpark.com/v1/getServerTime?type=1&nc=` 返回毫秒明文时间戳。
- 余票三层：
  1. `POST /onestop/gql` `GetPlaySeqsForDate` → 每场 `isSeatRemain` + 每价位 `remainCount`（精确值）
  2. `GET /onestop/api/seats/grades` → 价位名/价格/颜色/remainCount
  3. `GET /onestop/api/seatStatus?blockKeys=` → **状态串**，`data[i]` 对应第 i 个 blockKey，
     长度 = `ceil(区块座位数/4)`（每字符 4 座）。
- **`seatStatus` 的 `'0'` = 无余票**：抓包时全场售罄（remainCount=0）→ 34821 字符全 `'0'`，反证成立。
  插件因此按"非 '0' = 有票"判定，无需知道非零字符的确切编码（位图 or 计数待有余票时再校准）。
- `GET /onestop/api/seatMeta?blockKeys=`（**每次最多 2 区块**，30~130KB）→ 座位 id/价位(songGradeName)
  /排号 `rowNo`（如 `E구역 10열`，**区域名的唯一来源**）/坐标/`isExposable`。
- `GET /onestop/api/seats/block-data` → 46 区块绝对坐标（自绘座位图）。舞台在图上方 y≈108~156。
- 官网自身 `seatStatus` 轮询中位 **4.55s**、最快 2.61s；选座前有**图形验证码**（不绕过）。

## v0.3：有票场次抓包 → seatStatus 位级解码 + 精确定位（重大修正）

### seatStatus 编码（已解开，v0.2 的"1~4 上下界"作废）
- `pos` = 该座位在 **seatMeta 数组中的下标**（seatInfoId 升序，**不是** rowIdx/colIdx 栅格序）
- 字符 = `pos >> 2`；取第 `3 - (pos & 3)` 位（**MSB 优先**）；**1 = 可购，0 = 不可购**
- 四条独立证据：① 8/8 区块 `len = ceil(座位数/4)`；② 轮询中 `001:001` 第 48 字符 `8`→`0`
  紧随其后就是 `seats/select`，被锁 `seatInfoId ...:194` 在数组中下标恰为 192 → 字符 48 / 位 3，
  四种假设只有"数组序+MSB"自洽，且该次变化只涉及 1 个字符；③ 售罄场次全 `0`；
  ④ 档位置位数 ≈ `grades.remainCount`（Assigned Seat 43=43；STANDING 849 vs 852）。
- **坑**：`buildCatalog` 必须保持 seatMeta 原序，否则状态位整体错位。

### 坐标系（定位的关键）
- `posLeft = block.absoluteLeft + colIdx × 3.0`，`posTop = block.absoluteTop + rowIdx × 3.0`
- 座位画布空间 = 场馆 SVG 的 viewBox（实测 `0 0 316 305`）→ 找到页面上的该 SVG/`img[src*="/svg/"]`
  即可按 `scale = 渲染宽 / viewBox 宽` 把座位坐标换算成屏幕像素，叠加定位标记。
