# NOL Scout

当前版本：**0.8.3**。用于 NOL World / Interpark 选座页的 Chrome 插件，按区域、价位、张数和位置偏好筛选余票，提供连座排序、座位定位、地图、通知及选座倒计时；可选本地填写文字验证码和自动预选、锁票。

## 安装与使用

1. 在 `chrome://extensions` 开启开发者模式，选择「加载已解压的扩展程序」，加载本目录 `extension/`。更新后重新加载插件，并刷新选座页。
2. 正常进入网站选座页，等待插件获取会话与座位目录，设置区域、价位、张数和位置偏好，开始扫描。命中后显示首选与备选座位，可定位到页面或查看全屏地图。
3. 点击插件图标，在「设置」中按需开启以下选项，并点击「保存设置」。设置与选座面板同步，未保存的勾选不会被定时刷新覆盖。

| 设置 | 行为 | 默认 |
| --- | --- | --- |
| 自动填写文字验证码并验证（本地识别） | 本地识别六位字母，填写后通过网站按钮验证 | 关闭 |
| 找到最优座位后自动预选并锁票 | 验证通过后，复核首选座位并执行网站选座流程 | 关闭 |
| 验证码期自动开扫 | 验证码出现时启动余票扫描 | 关闭 |

选座计时不会因验证码或刷新暂停；会话过期后停止扫描，需要重新进入有效选座会话。扫描中修改范围后，应重启扫描使新范围生效。

- 分别处理蓝底黄字、绿底青字；读取页面已有验证状态，支持插件启动前已完成验证的情况。

- 将自动填码、自动锁票加入插件设置；修复未保存勾选被定时刷新覆盖及其他设置保存时丢失开关的问题。新增新 HAR、页面流程和浏览器回归。

## 构建与验证

在 `extension/` 目录执行：

```sh
node tools/build.mjs
node test/verify-har.mjs ../tickets.interpark.com.har
node test/new-har.mjs ../tickets.interpark.com_new.har
node test/automation.mjs ../tickets.interpark.com_new.har
node test/page-automation.mjs
```

可选浏览器测试：`node test/browser-automation.cjs`、`node test/browser-mv3.cjs`。用 `PLAYWRIGHT_MODULE` 指定 Playwright 模块；MV3 测试还需 `TEST_CHROME_EXECUTABLE` 指向支持加载未打包扩展的 Chrome for Testing。

已通过旧 HAR 228 项回归、新 HAR 契约与异常分支、浏览器填码及预选确认流程、设置保存和真实 MV3 链路测试。两份 HAR 的验证码均本地识别正确，置信度为 87。浏览器测试拦截网站请求并模拟页面控制器，**尚未验证真实购票服务器联调**。

## 使用边界

- 不自动付款。滑块或无法可靠识别的验证码需人工处理；页面结构变化时可能暂停自动操作。
- 多座位操作中途失败时，不自动释放已预选座位、切换候选或重复提交，请检查页面状态。
- 大场馆扫描会分批请求；超过 12,000 个可见座位时地图使用区块热力显示。页面座位不再以 DOM 绘制时，定位精度可能下降。
- OCR 引擎、模型版本和校验信息见 `vendor/ocr/SOURCES.json`，许可证附在同目录。
